# Git & GitHub Workshop

Welcome to the hands-on repository for our Git & GitHub introductory session.

This repository is designed so you can practice the most important Git workflow:
creating a branch → making a small change → committing → opening a Pull Request → merging.

## How to participate

1. Choose an Issue that matches your level and interest.
2. Create a new branch from `main`.
3. Make the requested change.
4. Commit your changes with a clear message.
5. Open a Pull Request.
6. Wait for a short review and merge.

You can work directly in the browser on GitHub (recommended) or clone the repository if Git is available on your machine.

## Difficulty levels

- **[Easy]** — 3–7 minutes. Perfect if this is your first time.
- **[Medium]** — 8–15 minutes. A bit more thinking required.
- **[Challenge]** — Optional. For those who want a bigger task.

## Available modules

- `cyber/` — Cybersecurity related tasks
- `ml/` — Machine Learning related tasks
- `python/` — Python tasks
- `web/` — Simple web / JavaScript tasks (optional)

## Tips

- Keep your changes small and focused.
- Write clear commit messages (example: `Fix typo in README` or `Add empty list check`).
- You can reference the Issue number in your Pull Request description (e.g. `Fixes #3`).
- Don’t worry about making mistakes — this repository exists for practice.

## Need help?

Ask during the session or check the additional resources shared by the instructor.
